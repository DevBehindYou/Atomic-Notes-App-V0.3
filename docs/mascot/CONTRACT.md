# Mascot catalog contract v1

Accepted code base: `7468460`. Artwork is the user-supplied `assets/Atomic Notes Mascot` collection, independently pinned by the SHA-256 of the authoritative audit manifest in `catalog-v1.json`. The compact manifest retains all 52 metadata records without private filesystem paths or per-frame evidence. No image bytes were transformed. This document records provenance, not a new licensing claim.

`MascotCatalog.all` is a const, numerically ordered list of 13 definitions; each const clip list contains slots 1 through 4. `defaultId` is `061-cubie`; `defaultMascot` returns it; `findById` returns null for an unknown exact ID. Clip IDs are original filename stems. `sourcePath` preserves original relative case/spaces, `originalFilename` is the release asset filename. Metadata pins bytes, SHA-256, dimensions, frame count and encoded one-cycle duration. Only Cubie has non-null `bundledAssetPath`. There is no published origin yet; MSC09 must pin reviewed public versioned URLs before delivery.

The resolver interface is `Future<MascotAssetLease> openVerifiedClip(MascotClip clip)`. A lease exposes `Uint8List get bytes` and idempotent asynchronous `close()`. Hold the lease until decoder cleanup completes. Implementations verify local bytes at read/install boundaries, coordinate file removal with leases and never fetch from rendering callbacks. MSC09 owns native implementation; MSC03 uses fakes. Do not mutate leased bytes. No default implementation or network operation is introduced here.

Bundle addition: four unchanged Cubie GIFs, 2,208,045 encoded bytes. The remaining twelve characters are metadata only (16,513,252 encoded bytes). This is not a measured APK/AAB delta. Existing old mascot asset declarations remain because current widgets still use them. MSC05 owns atomic call-site switching and obsolete declaration removal while preserving brand assets. Until that integration the app continues its current mascot behavior.

Run `dart run tool/verify_mascot_catalog.dart` from the app root. Pass the authoritative audit manifest path as its single optional argument to verify audit agreement as well. The tool verifies catalog metadata, bundled file hashes, exactly four bundled files, no path escapes and the new asset declaration. Tests freeze catalog lookup, totals, immutability and default semantics. Renderer, persistence, download/storage, bootstrap and note/auth behavior belong to later tasks.
